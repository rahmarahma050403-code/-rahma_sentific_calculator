    HMI Design Choices

    1. Visual grouping: scientific functions, memory controls and number keys are placed in separate groups.

    2. Inverse trigonometry: sin⁻¹, cos⁻¹ and tan⁻¹ calculate arcsin, arccos and arctan. Their answers follow the selected DEG/RAD mode.

    3. Immediate feedback: the display shows the expression, result and clear error messages.

    4. Consistency and accessibility: buttons keep predictable behavior, keyboard input is supported, and the light/dark themes improve viewing comfort.
